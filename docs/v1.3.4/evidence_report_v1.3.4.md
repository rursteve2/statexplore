## Benchmarks

See `benchmark_v1.3.4.md`. No common workload regressed by more than 20 % (54B 100k rows: +5.7 %).

The 51H3 bootstrap is 63 % slower: it no longer reuses wrong fits. This is a correctness-driven change, reported for
owner review.

## Limitations and residual risk

- **47C exact count replay** [1,0,1,6,1,0] is PARTIAL. The original 47C search settings are not in the handoff. The
  mechanism is reproduced and fixed.
- **Optimizer-path sensitivity** of non-converged lme4 fits to term order remains. Those fits are flagged; selections
  are unaffected.
- **V134-009** is not reproduced from the saved state. Hardening and reason states were added. The installed-exe
  restart was not run; two source processes were used instead.
- **Physical DPI and clean-machine install** were not run (owner-approved deferrals, 2026-11-27).
- **Earlier results.** Bootstrap validations and GEE workflow B comparisons produced by v1.3.3 or earlier may be wrong
  and should be rerun. Their stored rows are kept as history (fit rules 3) and are never reused.

## Decision

**GO** for release, under these conditions:

- All P0 / P1 / P2 items are fixed and verified by real-R tests against independent oracles.
- No mandatory test failed.
- The only NOT RUN items are owner-approved deferrals.

This is not a claim that the program is validated for publication or for all datasets.
